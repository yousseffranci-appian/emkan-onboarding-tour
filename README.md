# Emkan Partner Onboarding: guided tour

A self-contained, click-through tour (26 stops, ~15 min) of the Emkan merchant onboarding POC built on Appian. It follows one partner, Miraj Interiors, from first enquiry to activation, and shows how the process itself is changed: adding the AML sign-off step, assignment, form, escalation, publish and versions.

- Open `index.html`, or the GitHub Pages site. Use ← → to move and Esc for the overview, or append `#n` to the URL to jump to a stop.
- Screens were captured from the live POC environment on 2 October 2026.
- Bank and registry integrations (Wathq, Nafath, IBAN, T24, AML) are deterministic simulations, labelled as such in the app. All partner data is fictional.

Source and capture scripts live in the POC project (`demo-tour/`), not here.
